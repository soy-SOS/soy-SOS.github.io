### Verortung der Quantitativen empirischen Forschung

Die Methodik und Statistik bildet einen Bestandteil der Empirischen Sozialforschung ab.

```
-- Sozialforschung
    |
    +-- Theorie
    |
    +-- Empirie
        |
        +-- Quantitativ (grosse Fallzahlen)
        |
        +-- Qualitativ (Tiefenverständnis)
        |
        +-- Mixed Methods (Kombination)
        |
        +-- Computational (Text- & Netzwerkdaten)
```

{: .important-title}
> Definition: Empirie
>
> Empirie ist das Untersuchen von Fragestellungen auf Basis von Beobachtungen und Daten.
>
> Das Ziel der empirischen Forschung ist es grundlegend immer, einen vermeintlichen Zusammenhang zwischen Konzepten zu ergründen.

#### Analyseebenen

Das Forschungsobjekt und die Analysebene können verschiedend umfassend sein, weshalb es zwingend notwendig ist, die Untersuchungseinheit zu kennen und damiteinhergehende. Je nach Untersuchungseinheit liegt der Fokus und mögliche Knackpunkte der Forschung in einem anderen Bereich.

```
Internationales System
|
+-- Staat
    |
    +-- Partei
        |
        +-- Gruppe
            |
            +-- Individuum
```

### Grundlagen der empirischen Sozialforschung

Das Verfahren befolgt immer einen fixen Ablauf, die sog. Analysekette:

```
+-- Theorie +
      |     |
      |     |
+-- Frage   |
      |     |
      +---- Konzept
            |
            +-- Operationalisierung
                |
                +-- Daten
                    |
                    +-- Antwort
                        |
                        + neue Fragestellungen
```

{: .important-title }
> Definition Konzept
>
> Konzepte sind klar definierte, abstrakte Ideen. Sie haben keine inherenten Messgrössen. Konzepte sind Bausteine von Theorien, Container für empirische Phänomene und Grundlage für deren Messung.

Es gibt verschiedene Arten Konzepte genauer zu beschreiben:

| stabil | Konzept gibt es schon lange, Bedeutung weitgehend unbestritten. |
| umstritten | Konzept wird immer wieder neu definiert. |
| latent | Konzept ist nicht direkt beobachtbar, gemessen werden Indikatoren. |

Konzepte können auf verschiedene Weisen erstellt werden. Drei wichtige, miteinander Konkurrierende Ansichten sind folgende.

| Wer | Wie |
| :--- | :--- |
| Aristoteles | Konzept definieren durch wesentliche Merkmale, notwendige und hinreichende Bedingungen für Anwedung |
| Wittgenstein | Konzepte entstehen durch Relationen zwischen Dingen. |
| Bollen | Konzepte sind latente Variablen, die sich in verschiedenen Messinstrumenten widerspiegeln. |

{: .important-title }
> Bedingungen: notwendig / hinreichend
>
> Erklärung mithilfe Aspekt A und Konzept K.
>
> {: .note }
> **notwendig** heisst A ist zwingender Bestandteil von K, K kann ohne A nicht erfüllt sein.
> `K ⇒ A (K impliziert A)`
>
> {: .note }
> **hinreichend** heisst wenn A erfüllt ist, tritt K ein.
> `A ⇒ K (A impliziert K)`

{: .important-title }
> Definition Theorie
>
> Die Theorie ist eine Annahme bezüglich der Beziehung zwischen verschiedenen Konzepten und ihren Mechanismen. Sie informiert Frage, wie auch Konzept.

Theorie beinhaltet eine begründete Auswahl möglicher Mechanismen. Ein Mechanismus ist die Relation zwischen zwei Konzepten. Durch das Vernetzen von Konzepten in einem Mechanismus, werden Erwartungen sichtbar gemacht.

{: .important-title }
> Definition Frage
>
> Die Frage, bzw wissenschaftliche Fragestellung, ist das Untersuchungsobjekt der empirischen Sozialforschung. Sie bringt Konzepte in ein theorieinformiertes Verhältnis.
> Sie ist immer offen formuliert, die theoretische Begründung und Erwartung sind Bestandteile der Hypothese.

Forschungsfragen müssen eine wissenschaftliche Relevanz haben, das heisst, ihre Antworten tragen eine **neue Erkenntnis** zur Wissenschaft bei. Somit ist es zwingen, dass der **aktuelle Forschungsstand** abgeklärt werden muss, ansonsten besteht die Chance, dass die Frage schon im aktuellen Wissensstand beantwortet ist.

Es gibt verschiedene Fragetypen:

| Typ | Ziel |
| :-- | :--- |
| Deskriptiv | Verteilung oder Muster beschreiben |
| Vergleichend | Systematisches Vergleichen von Fällen |
| Erklärend | Ursachen und Mechanismen begründen |
| Evaluativ | Wirkung von Interventionen beurteilen |
| Normativ | Kriterien begründen und anwenden |

Die Hypothese formuliert dann, basierend auf Theorie und Fragestellung eine Annahme. Die Hypothese beinhaltet den Mechanismus in der Form (UV) -> (AV).

{: .important-title }
> Definition Operationalisierung
>
> Operationalisierung ist der Prozess, der dazu führt, dass die Konzepte der Fragestellung messbar werden.

Die Operationalisierung ist die Brücke zwischen theoretischer Grundlage, Fragestellung und Daten.
Die wichtigsten Bestandteile davon sind:

- Idikatoren entwickeln / festlegen / bestimmen, die das Konzept widerspiegeln
- Datenquellen definieren, die die Indikatoren messen

Resultierende Messungen werden in Variablen gespeichert.

{: .important-title }
> Definition Variable
>
> Variablen sind das Speichermedium für Messwerte. Sie müssen **reliabel** und **valide** sein.

Bei der Validität unterscheidet man zwischen:

- face validity: offensichtlich logisch
- inhaltliche Validität: Indikatoren inhaltlich stimmig
- Konstruktvalidität: Indikatoren vom Konzept abgeleitet

Variablentypen sind ausserdem kategorisierbar:

```
Variable
|
+-- Typ
    |
    +-- Kategorial
    |   |
    |   +-- Nominal (Kategorien)
    |   |   ⇒ A + D
    |   |
    |   +-- Ordinal (Kategorien mit Rangordnung)
    |       ⇒ A + D + R
    |
    |
    +-- Numerisch
        |
        +-- Intervall (Kategorien mit Rang auf Skala mit gleichen Abständen)
        |   ⇒ A + D + R + I
        |
        +-- Ratio (Kategorien mit Rang auf gleichm. Skala und abs. Nullpunkt)
            ⇒ A + D + R + I + V
```

Latente Konzepte können verschieden Operationalisiert werden:

- 1 Indikator, der das Konzept abdeckt
- Index: mehrere Indikatoren, die kombiniert zu einem Gesamtwert führen.

{: .important-title }
> Definition Daten
>
> Daten sind die Messwerte, welche die Konzepte der Fragestellung repräsentieren.

Die Daten werden in Datensätzen gespeichert, welche folgende Elemente umfassen:

- Datensatz = Tabelle
- Zeile = Beobachtung (Fälle)
- Spalten = Variablen
- Zelle = Wert
- ID = Identifier (macht jede Beobachtung eindeutig)

{: .important-title }
> Definition Antwort
>
> Die Antwort ist die Schlussfolgerung, welche die Fragestellung beantwortet. Sie erfolgt basiert auf den Daten.

Antworten haben folgende Elemente:

1. Describe (Beschreiben der Daten)
2. Infer (Inferenz / Schlussfolgerung aus dem, was in den Daten zu beobachten ist)
3. Predict (Voraussage, was das für die Zukunft bedeutet)

### Statistische Grössen

#### Mittelwert

{: .important-title}
> Definition Mittelwert
>
> Der Mittelwert (auch arithmetisches Mittel, Durchschnitt) ist die Summe aller Werte geteilt durch deren Anzahl.

```py
def mittelwert(data):
    sum = 0
    N = data.__len__
    for d in data:
        sum += d
    return sum / N.
```

#### Modus

{: .important-title}
> Definition Modus
>
> Der Modus ist der Wert mit der grössten absoluten Häufigkeit.

```py
def modus(data):
    unique_data_values = []
    sorted_data = data.sort()

    modus = 0
    N_modus = 0

    for d in sorted_data:
        d_count = sorted_data.count(d)
        if d_count > N_modus:
            modus = d
            N_modus = d_count

    return modus
```
